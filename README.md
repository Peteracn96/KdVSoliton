# KdV Soliton

This repository is for exploring soliton solutions of the
Korteweg–de Vries (KdV) equation.

## About

The KdV equation is a model for weakly nonlinear, dispersive waves. Its
solitary-wave solutions maintain their shape as they travel, making them a
classic example of a soliton.
